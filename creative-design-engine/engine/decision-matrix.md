# Decision matrix

Hero × beat → composition → skills. **Ranking guidance, not a lookup table.** The asset manifest has already removed impossible rows before this is consulted, and the intended viewer response breaks remaining ties.

An empty cell means that pairing is usually a mistake — not that it is forbidden. A comparison with a face hero and no second product, for example, is a piece that has not decided what it is comparing.

## Worked selections

| Situation | Direction | Why |
|---|---|---|
| two products + portrait + comparison story | A + Creator + B, `/split-compare` | the creator adjudicates rather than competes; matched framing carries the comparison |
| one excellent product photo, weak portrait | Product Dominant, `/product-hero` | lead with the asset that is actually good; a weak portrait costs more than it adds |
| strong reaction portrait + product | Face + Product, `/product-hero` + `/sketch-overlay` | the reaction is the hook, the product is the proof, the drawn mark ties them |
| AI / software story | Screen Dominant, `/floating-ui` + `/sketch-overlay` | the interface is the evidence; the mark identifies the one feature that matters |
| foldable / adaptive-content story | Device / Foldable, `/fold-reveal` or `/device-morph`; `/before-after-morph` and `/screen-within-screen` where the point is recomposition | the format change *is* the idea, so the visual must perform it |
| no usable imagery | Editorial, `/number-impact` or `/poster-mode` | type-led work is legitimate; a stretched weak photo is not |

## Using it

Rank, do not look up. Two situations with the same hero and beat can land differently on assets alone — that is the engine working, not failing.
