# Visual language vs layout

A channel is recognised by its **treatment**, not by its **layout**. These are
different things, and conflating them is how a strong identity turns into a
template that tires.

## What stays fixed

Recognition is carried by the parts that do not depend on what the story is:

| Carrier | What is fixed |
|---|---|
| lighting / mood | the same tonal world across pieces |
| typography | one type voice, one hierarchy, consistent case and weight |
| accent colours | the same small set, used for the same meanings |
| annotation language | the same marks, drawn the same way, meaning the same thing |
| UI card treatment | one surface, radius, border and depth behaviour |
| subject cutout style | the same separation treatment and edge quality |
| watermark / mark behaviour | same corner, same scale ratio, same restraint |
| depth / glow treatment | the same tiering rules, used sparingly |
| content-family cues | a family reads as itself before the title is read |

## What must vary

Composition. Every time, per story.

Valid variation includes: subject centred with supporting interface · subject
holding the product · product dominant · subject with product and cards ·
large hook with a small subject · comparison split · capture-driven ·
environment or desk driven · minimal premium.

## The rule

> **Fixed language, variable layout.**

If two pieces differ only in their photograph, the layout has become the
identity, and the identity has become a template. If two pieces share no
treatment, there is no channel — only separate pieces.

A composition is chosen from the **story and the available assets**. Repetition
of layout is never a goal in itself; it is what happens when the decision was
skipped.

## How this binds the engine

- The decision framework ranks compositions per job. A composition that won last
  time gets no advantage this time.
- The asset manifest can veto a composition, and often does — a layout needing a
  subject frame is not a candidate without one.
- Treatment is read from the brand profile and applied identically whichever
  composition wins. Nothing in the fixed column above is a per-job decision.
