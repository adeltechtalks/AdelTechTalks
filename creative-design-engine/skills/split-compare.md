# /split-compare

**Show two things side by side at matched scale so the viewer compares rather than ranks.**

| | |
|---|---|
| Mode | Both |
| Best story beats | comparison, proof, challenge |
| Best content types | A vs B reviews, competitor comparisons, before/after |
| Required assets | two frames at matched scale, angle and lighting |
| Optional assets | a divider, a verdict mark, a third element adjudicating |
| Max combinations | one supporting skill — usually `/feature-callout` |

## When to use it
The piece genuinely is a comparison and both assets are photographed comparably.

## When NOT to use it
The two frames do not match. Mismatched framing favours one side before a word is read, which makes the comparison dishonest. Say the frames do not match rather than cropping around it. Never duplicate one frame into both halves.

## Composition logic
Equal weight, equal scale, equal treatment. A hard divider, not a soft blend — the viewer must see two states instantly. Any adjudicating element sits between, smaller than both.

## Motion logic
Both sides arrive together, or the second arrives to meet the first. Never animate one side more elaborately.

## Brand OS rules
Divider and labels from the profile. Both halves share one grade.

## Platform considerations
Halves become small quickly; at feed size each side must still be identifiable. On vertical, stack rather than narrow.

## Arabic / English considerations
Label order follows reading direction: in RTL the first state sits on the right.

## Example
Two objects at identical scale either side of a thin rule, one label each.

## Anti-patterns
One side larger · different lighting per side · a verdict stated before the comparison is shown.
