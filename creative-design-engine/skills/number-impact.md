# /number-impact

**Make a single figure the whole composition.**

| | |
|---|---|
| Mode | Both |
| Best story beats | proof, hook, reveal |
| Best content types | benchmarks, specs, results, milestones, pricing |
| Required assets | one number that genuinely matters |
| Optional assets | a supporting label, a product frame held back |
| Max combinations | one supporting skill — usually `/feature-callout` |

## When to use it
One figure carries the story and is surprising on its own. Works with no photography at all.

## When NOT to use it
The number needs context to be impressive. A figure requiring a sentence of setup is not an impact number — it belongs in `/data-visual`.

## Composition logic
The figure is the largest element by a wide margin. One short label. Everything else recedes. Figures set in the profile's tabular face so digits align.

## Motion logic
Count up only if the count is short and the end value lands hard. Otherwise cut to the final figure.

## Brand OS rules
Figure face and scale from the profile. Digit convention follows the profile's language rules.

## Platform considerations
Survives feed size better than almost anything. Strong for square previews since a single figure centres naturally.

## Arabic / English considerations
Follow the profile's digit rule — many brands use Western digits in both scripts. Never mix digit systems in one composition.

## Example
A single large figure with a two-word label beneath it on a flat ground.

## Anti-patterns
Three numbers · a number with a decimal that does not matter · false precision.
