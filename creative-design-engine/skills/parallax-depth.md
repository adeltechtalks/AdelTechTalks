# /parallax-depth

**Separate foreground, subject and background so a still image gains dimensionality.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | reveal, hook |
| Best content types | talking head, product, environment, cinematic openers |
| Required assets | a frame with separable layers, or a subject cutout plus a ground |
| Optional assets | a foreground element to pass in front |
| Max combinations | one supporting skill — usually `/light-sweep` |

## When to use it
A single still needs to feel alive without a cut. Strongest where a genuine foreground object exists.

## When NOT to use it
The image cannot be separated cleanly. Bad edges are more visible in motion than in stills, and a haloed cutout destroys the premium read instantly.

## Composition logic
Three planes maximum: foreground, subject, ground. Subject stays sharpest.

## Motion logic
Slow, small, continuous drift on different rates per plane. Subtlety is the whole point — if the viewer notices the technique, it is too much.

## Brand OS rules
Motion range and duration from the profile. No added blur beyond what the ground already has.

## Platform considerations
Reads on large screens; largely lost at feed size. Do not rely on it to carry a thumbnail.

## Arabic / English considerations
Nothing language-specific.

## Example
A desk object drifting slightly slower than the blurred shelf behind it.

## Anti-patterns
Large parallax offsets · a foreground plane that crosses the face · parallax plus a camera push at once.
