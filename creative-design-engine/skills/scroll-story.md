# /scroll-story

**Move through a long composition so a sequence unfolds as one continuous shot.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | explanation, transformation, proof |
| Best content types | process explainers, timelines, comparisons over time, long lists |
| Required assets | content laid out longer than the frame |
| Optional assets | waypoint markers |
| Max combinations | one supporting skill — usually `/freeze-frame-note` |

## When to use it
The content has a genuine sequence and the relationship between steps matters. The continuous move preserves the relationship a cut would break.

## When NOT to use it
The steps are unrelated. Scrolling past unrelated items is a list read aloud slowly.

## Composition logic
Lay out the full composition first; the camera path comes second. If the static layout does not work, the scroll will not save it.

## Motion logic
Constant speed with eased start and stop, pausing briefly at each waypoint. One direction only — reversing is disorienting.

## Brand OS rules
Pacing from the profile's motion charter. Spacing between waypoints from its scale.

## Platform considerations
Natural on vertical. On horizontal it usually wants to be a carousel instead.

## Arabic / English considerations
Scroll direction follows reading direction: RTL content moves right to left.

## Example
A vertical strip of four stages, the frame travelling down and resting on each.

## Anti-patterns
Scrolling faster than reading · scrolling both axes · a scroll with one waypoint.
