# /cutout-collage

**Compose several cut-out subjects into one deliberate arrangement with depth.**

| | |
|---|---|
| Mode | Static |
| Best story beats | reveal, explanation, joke |
| Best content types | multi-product, roundups, gift guides, comparisons of more than two |
| Required assets | transparent cutouts — supplied, not assumed |
| Optional assets | a flat ground, a drawn mark |
| Max combinations | one supporting skill — usually `/sketch-overlay` |

## When to use it
Several objects must coexist and no single one is the hero. Overlap creates depth that a grid cannot.

## When NOT to use it
No cutouts exist. Background removal is a production step, not something to assume — if the manifest has no cutout, this skill is unavailable. Also avoid past four objects, where it becomes a catalogue.

## Composition logic
Overlap deliberately, vary scale to create depth, let at least one subject bleed off an edge. Avoid even spacing — a row of equal objects is a product grid.

## Motion logic
_Static skill — no motion logic._

## Brand OS rules
Ground and shadow from the profile. One shadow treatment across all pieces or the collage falls apart.

## Platform considerations
Weak at small sizes past three objects. On vertical, stack rather than spread.

## Arabic / English considerations
Labels, if any, follow the profile's language rules.

## Example
Three cutouts at three scales, overlapping diagonally, largest bleeding off the lower right.

## Anti-patterns
Evenly spaced objects at identical scale · inconsistent shadow directions · a fourth object added because it was available.
