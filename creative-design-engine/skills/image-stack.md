# /image-stack

**Layer several frames as an overlapping stack so a set reads as one object.**

| | |
|---|---|
| Mode | Static |
| Best story beats | reveal, explanation |
| Best content types | roundups, collections, series, multi-shot reviews |
| Required assets | three or more frames that belong together |
| Optional assets | a consistent border or shadow |
| Max combinations | one supporting skill — usually `/editorial-grid` |

## When to use it
Several images must be present but none is the hero, and their being a set is the point.

## When NOT to use it
One image is clearly stronger. Stacking then buries the best asset to be fair to the others, which serves nobody.

## Composition logic
Consistent offset and rotation between layers, one frame clearly on top and readable. Depth from consistent shadow, not from varying it.

## Motion logic
_Static skill — no motion logic._

## Brand OS rules
Radius, border and shadow from the profile — one treatment across every layer.

## Platform considerations
Weak at feed size past three layers. On vertical, stack downward rather than fanning.

## Arabic / English considerations
Stack direction may follow reading direction.

## Example
Three frames fanned with a consistent 8-degree step, the top one fully visible.

## Anti-patterns
Random rotations · six layers · different shadows per layer.
