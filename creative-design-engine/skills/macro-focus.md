# /macro-focus

**Go very close on one detail so texture, material or precision becomes the subject.**

| | |
|---|---|
| Mode | Both |
| Best story beats | reveal, proof |
| Best content types | materials, build quality, craft, premium product |
| Required assets | a macro or close frame that is genuinely sharp |
| Optional assets | a wider frame for context |
| Max combinations | one supporting skill — usually `/light-sweep` |

## When to use it
Detail is the argument — finish, texture, tolerance, craft. Extremely strong for premium reads because closeness implies confidence.

## When NOT to use it
The detail is not sharp. Upscaled softness at macro scale looks like a mistake, not intimacy. Also not when the viewer needs to identify the whole object.

## Composition logic
Fill the frame. Let the subject bleed off every edge. One point of focus, everything else falling away.

## Motion logic
A slow drift across the surface, or a rack of focus landing on the detail. One move.

## Brand OS rules
Grade from the profile. Do not oversaturate to make a material look richer than it is.

## Platform considerations
Reads beautifully at any size because it is one texture. Excellent for square previews.

## Arabic / English considerations
Copy is usually one or two words, or none.

## Example
A hinge filling the frame, the rest of the device out of focus behind it.

## Anti-patterns
A macro that is actually a crop of a wide shot · macro on a low-resolution source · adding a second focal point.
