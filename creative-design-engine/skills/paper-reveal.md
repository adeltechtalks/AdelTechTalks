# /paper-reveal

**Reveal by peeling, sliding or lifting a covering layer, as if uncovering something physical.**

| | |
|---|---|
| Mode | Both |
| Best story beats | reveal, curiosity |
| Best content types | unboxing, announcements, launches, before/after |
| Required assets | the thing being revealed |
| Optional assets | a texture or plain field acting as the cover |
| Max combinations | one supporting skill — usually `/sketch-overlay` |

## When to use it
The piece benefits from a moment of concealment. Works when the revealed thing is genuinely worth the delay.

## When NOT to use it
The subject is already visible elsewhere in the frame, or the reveal is longer than the payoff justifies.

## Composition logic
Static use: the covering layer is partly pulled back, subject visible in the gap — concealment implied in one frame.

## Motion logic
A single directional peel or slide, decelerating. The cover leaves the frame entirely; a cover that lingers reads as an unfinished transition.

## Brand OS rules
The covering layer uses a profile surface colour, never an invented texture. No paper grain unless the profile carries one.

## Platform considerations
On short vertical, the reveal must complete inside the first beat. On static, the partial-peel frame must read instantly.

## Arabic / English considerations
Nothing language-specific.

## Example
A flat field sliding away to expose a product already in position behind it.

## Anti-patterns
Peeling to reveal text only · multiple layers peeling in sequence · a literal paper-curl illustration.
