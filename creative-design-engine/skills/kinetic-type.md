# /kinetic-type

**Let typography carry the motion when the words are the content.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | hook, explanation, CTA |
| Best content types | quotes, claims, statements, lists, type-led openers |
| Required assets | copy worth animating |
| Optional assets | a held-back ground or image |
| Max combinations | one supporting skill — usually `/light-sweep` |

## When to use it
The line is the subject and no image is strong enough to lead. Also the honest choice when assets are thin.

## When NOT to use it
The copy is long. Kinetic type on a paragraph is unreadable, and it tempts the writer to add words because motion feels like it buys time. It does not.

## Composition logic
One line, one idea, one emphasis. Words enter in reading order.

## Motion logic
Enter, settle, hold. The hold is longer than feels right in the editor — reading takes longer than watching. Never loop.

## Brand OS rules
Type scale, weight and tracking from the profile. Never letter-space a script the profile forbids letter-spacing.

## Platform considerations
Excellent on short vertical. On static surfaces this skill does not apply — use an editorial strategy.

## Arabic / English considerations
RTL copy enters right to left. Mixed-script lines keep Latin terms as isolated islands and must not reverse order mid-animation — verify with real copy.

## Example
A three-word claim landing one word at a time, the last word held twice as long.

## Anti-patterns
Every word animating differently · bouncing · a sentence treated as a headline.
