# /freeze-frame-note

**Stop on a frame and annotate it, so motion pauses for a point to be made.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | proof, explanation, joke |
| Best content types | reviews, tutorials, reactions, breakdowns |
| Required assets | footage with a moment worth stopping on |
| Optional assets | a drawn mark or short label |
| Max combinations | this IS usually the supporting skill |

## When to use it
One moment in a sequence carries the evidence and needs more time than real time allows.

## When NOT to use it
The moment is not genuinely important. Freezing for emphasis that is not there teaches the viewer to distrust the next freeze.

## Composition logic
The frozen frame must be legible on its own — a blurred or mid-motion frame does not become clearer by being held.

## Motion logic
Hard stop, annotate, hold, resume. The stop is abrupt; the resume is not. Once per scene at most.

## Brand OS rules
Annotation follows the profile's annotation colour and rules.

## Platform considerations
Costs a beat; on very short formats it may be the only beat, which can be the right call.

## Arabic / English considerations
Written notes follow the profile's script limits — many sketch faces carry no Arabic glyphs.

## Example
A demo pausing on the exact frame where a feature triggers, one circle drawn on it.

## Anti-patterns
Three freezes in one scene · freezing on a motion-blurred frame · freezing without annotating.
