# /magazine-cover

**Borrow editorial cover language — masthead, coverline, one portrait — for a premium statement.**

| | |
|---|---|
| Mode | Static |
| Best story beats | reveal, hook |
| Best content types | announcements, features, personal brand, milestone posts |
| Required assets | one strong portrait or hero object |
| Optional assets | coverlines, an issue-style label |
| Max combinations | one supporting skill — usually `/number-impact` |

## When to use it
The piece is a statement and the subject can carry a cover. Works when the image quality genuinely matches the ambition.

## When NOT to use it
The photograph is ordinary. Cover language raises expectations; an ordinary photo in a cover layout looks like a template someone filled in.

## Composition logic
Subject dominant and full-bleed. Type overlaps the subject deliberately — behind the shoulder, across the edge. That overlap is what separates a cover from a poster with a headline on it.

## Motion logic
_Static skill — no motion logic._

## Brand OS rules
The masthead is the brand's own wordmark at its approved treatment, never a decorative substitute. Type from the profile.

## Platform considerations
Beautiful at full size, weaker in feeds where coverlines vanish. Keep one line readable small.

## Arabic / English considerations
Coverline stack mirrors for RTL; the masthead does not mirror.

## Example
A portrait bleeding off three edges, the wordmark partly behind the head, two short coverlines down one side.

## Anti-patterns
Six coverlines · a barcode or fake issue number · a masthead competing with the subject.
