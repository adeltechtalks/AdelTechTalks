# /glass-overlay

**Lay a translucent frosted plane over imagery so text can sit on a busy frame.**

| | |
|---|---|
| Mode | Both |
| Best story beats | explanation, proof, CTA |
| Best content types | caption panels, spec overlays, quote cards |
| Required assets | an image busy enough to need separation |
| Optional assets | a hairline edge |
| Max combinations | none — this is already a surface treatment |

## When to use it
Text genuinely cannot survive on the image and a global grade is not enough. Rare, and rarer than designers think.

## When NOT to use it
A global grade would have worked. A visible panel edge turns a photograph into a card, and cards read as templates. Default to the grade; reach for glass only when the image is busy everywhere.

## Composition logic
One plane, one edge treatment, generous internal padding. It must read as a lens over the image, not a box on top of it.

## Motion logic
Fades in with the text it carries, never separately.

## Brand OS rules
Plate opacity, radius and edge from the profile. If the profile retires gradients, the plate is flat translucency and a single hairline — no soft-edged falloff.

## Platform considerations
At feed size the plate often reads as a grey box. Test small before committing.

## Arabic / English considerations
Padding is symmetric so the plate works in both directions.

## Example
A single frosted plane across the lower third of a busy photograph, one line of type inside it.

## Anti-patterns
Two stacked plates · a plate holding one short word · a plate used because the crop was lazy.
