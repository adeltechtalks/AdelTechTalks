# /exploded-view

**Separate an object into its parts to show construction or contents.**

| | |
|---|---|
| Mode | Both |
| Best story beats | explanation, reveal, proof |
| Best content types | teardowns, what's-in-the-box, build breakdowns, kit contents |
| Required assets | component frames or a cutout that can be separated |
| Optional assets | connecting lines, part labels |
| Max combinations | one supporting skill — usually `/feature-callout` |

## When to use it
The internal structure or the set of parts is the story. Strong for unboxing and teardown content.

## When NOT to use it
The parts are not visually distinct, or you have only an assembled photograph. Faking separation from one image looks exactly like faking it.

## Composition logic
Parts arranged along one axis with consistent spacing and a clear order. Alignment does the explaining.

## Motion logic
Parts separate outward together on one curve, then hold. Reassembly is a different beat; do not do both.

## Brand OS rules
Spacing from the profile's scale. Labels, if any, follow its type ramp.

## Platform considerations
Needs space — weak on short vertical and at feed size. Best on wide canvases and carousel slides.

## Arabic / English considerations
Part labels follow the profile's language rules; keep established Latin part names in Latin.

## Example
Four components spaced evenly along a diagonal, each with a one-word label.

## Anti-patterns
Parts at random angles · more parts than the canvas can hold · an explosion that hides the main body.
