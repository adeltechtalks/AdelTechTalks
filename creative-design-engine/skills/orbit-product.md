# /orbit-product

**Rotate around an object so its form is understood in three dimensions.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | reveal, proof |
| Best content types | product reveals, hardware, physical design |
| Required assets | orbit footage or a multi-angle sequence |
| Optional assets | a held-back ground |
| Max combinations | one supporting skill — usually `/light-sweep` |

## When to use it
The object's form genuinely rewards rotation — a shape, a hinge, a profile that a single angle hides.

## When NOT to use it
The object is flat or front-facing. Rotating a phone screen shows the back of a phone, which nobody wanted. Also never as a default product move.

## Composition logic
One axis, continuous. Object stays centred and stays the same size.

## Motion logic
Slow, constant, and stopping at a chosen hero angle — an orbit that loops endlessly has no argument. Under one rotation, always.

## Brand OS rules
Ground and duration from the profile.

## Platform considerations
Costly in time; on short vertical it may consume the whole hook for little payoff.

## Arabic / English considerations
Nothing language-specific.

## Example
A camera rotating 120 degrees and settling on the angle that shows the lens array.

## Anti-patterns
Endless looping rotation · orbiting a flat object · two axes at once.
