# /poster-mode

**Treat the frame as a poster: one image, one line, deliberate silence.**

| | |
|---|---|
| Mode | Static |
| Best story beats | hook, reveal, CTA |
| Best content types | announcements, launches, statements, minimal covers |
| Required assets | one strong image, or none |
| Optional assets | a single supporting line |
| Max combinations | none — restraint is the skill |

## When to use it
The subject or the claim is strong enough to need nothing else. Poster mode is a confidence bet: it looks expensive when the subject earns it and empty when it does not.

## When NOT to use it
The subject is ordinary. Restraint applied to a weak asset reads as an unfinished file, not as taste.

## Composition logic
One focal element, one line of type, large negative space that is clearly intentional — aligned, weighted, not merely empty.

## Motion logic
_Static skill — no motion logic._

## Brand OS rules
Type, ground and spacing from the profile. No decoration whatsoever.

## Platform considerations
Strong in feeds because there is nothing to lose at small size. Weak where the platform crops unpredictably: keep everything inside the centre-safe tile.

## Arabic / English considerations
Alignment follows reading direction. A centred poster line reads as generic in both.

## Example
A single object on a flat ground with three words set large in one corner.

## Anti-patterns
Adding a second line because the frame felt empty · centring everything · a poster with a small subject.
