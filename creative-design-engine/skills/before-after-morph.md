# /before-after-morph

**Move between two states of the same subject so the change itself is the content.**

| | |
|---|---|
| Mode | Motion |
| Best story beats | transformation, proof |
| Best content types | edits, upgrades, restorations, format changes, results |
| Required assets | two frames of the same subject in matched framing |
| Optional assets | a state label on each side |
| Max combinations | one supporting skill — usually `/freeze-frame-note` |

## When to use it
The change is visible and matters. The morph makes the difference undeniable in a way two separate shots cannot.

## When NOT to use it
Framing does not match, or the change is subtle enough to be lost at display size. A morph between mismatched frames advertises the mismatch.

## Composition logic
Identical framing, identical scale, identical crop. Only the state changes. Any labels sit in the same position on both sides.

## Motion logic
One transition, held at both ends. The 'after' hold is longer. Never morph back and forth — a loop removes the conclusion.

## Brand OS rules
Labels and duration from the profile. Both states share one grade, or the grade becomes the change.

## Platform considerations
Strong on short vertical. As a static fallback this becomes `/split-compare`.

## Arabic / English considerations
State labels follow reading direction: in RTL the first state sits on the right.

## Example
One composition becoming its recomposed version, the subject holding position while everything else re-lays.

## Anti-patterns
Mismatched framing · morphing between different subjects · a loop with no resting state.
