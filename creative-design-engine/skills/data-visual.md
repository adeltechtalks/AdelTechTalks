# /data-visual

**Turn figures into a shape the eye can compare before it reads.**

| | |
|---|---|
| Mode | Both |
| Best story beats | proof, comparison, explanation |
| Best content types | benchmarks, results, specs, performance, survey findings |
| Required assets | real data — values, not impressions |
| Optional assets | a source note |
| Max combinations | one supporting skill — usually `/number-impact` |

## When to use it
Several values must be compared and the comparison is the point. If there is only one figure, use `/number-impact`.

## When NOT to use it
The numbers are invented, rounded into meaninglessness, or fewer than three. A chart of two bars is a comparison; draw it as one.

## Composition logic
One chart, one message. The axis starts where honesty requires. Label directly on the marks rather than in a legend.

## Motion logic
Marks grow in once, in data order. No bouncing — physical overshoot on a number implies a value it never had.

## Brand OS rules
Chart colours from the profile's data palette if it has one, otherwise its neutral ramp with a single accent. Never the full brand palette as a categorical scale.

## Platform considerations
Charts die at feed size. On a thumbnail, show the shape and one figure, not the chart.

## Arabic / English considerations
Axis and label direction follow the profile's language rules; digits follow its digit rule.

## Example
Four bars, values labelled on the bars, one highlighted.

## Anti-patterns
A truncated axis that exaggerates · a legend requiring cross-reference · a pie chart with six slices · fabricated data.
