# Carousel examples

Reserved. The carousel work that exists in the host project predates the engine and was composed by hand; it has not yet been re-derived through the decision framework.

When it is, the run should show the thing a carousel tests that a thumbnail does not: **one beat per slide, and each slide readable alone**, because slides are re-shared individually. The interesting question is whether the engine chooses a different composition for slide 4 than for slide 1 given the same assets — if it does not, the per-slide beat is not being read.
