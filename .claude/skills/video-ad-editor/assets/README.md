# AdelTechTalks Brand Assets

This folder is intentionally asset-driven. Export approved brand elements from the Figma/Adobe source of truth and place them here:

- `logo.png` — transparent logo mark.
- `signature.png` — transparent Adel signature / creator mark.
- `opener.mp4` — 0.4–1.0s branded opener, 1080x1920, H.264, no required audio.
- `endcard.mp4` — 0.6–1.2s branded closer, 1080x1920, H.264, no required audio.

The editor must not invent replacements when an approved asset is missing. It may render without that optional brand slot and report what is missing.
