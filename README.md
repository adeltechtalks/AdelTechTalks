## The website

The site source is in [`site/`](./site) — an [Astro](https://astro.build) static
site built on the AdelTechTalks Design System.

- **To publish it, read [`site/LAUNCH.md`](./site/LAUNCH.md)**
- To change wording, videos, pillars or packages, edit
  [`site/src/site.config.ts`](./site/src/site.config.ts) — it is plain text.

### Cloudflare Pages build settings

| Setting | Value |
|---|---|
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | `site` |
