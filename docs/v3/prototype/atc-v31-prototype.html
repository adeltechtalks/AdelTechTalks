Prompt Arena

The full micro-experience: weak prompt → 60-second repair → animated score → breakdown → XP → badge → Try Another / Share / Save. Playable without an account, all the way to the reward.

Dimensions Clarity · Context · Constraints · Structure · Usefulness Scoring is deterministic Launch gate 9 challenges

The score is real, not a prop. Type anything and the five dimensions are graded by an actual rubric running in the page — the same shape the server-side Repair scorer would have. Ask for a named audience and Context lights; give a length or a "don't" and Constraints lights; ask for sections and Structure lights. The breakdown tells you which rule you missed and why it exists.

Nothing is gated before the value arrives. A signed-out visitor plays, scores, sees the breakdown, and is credited XP and a badge in-session. Only keeping it needs an account — that is the "Save your XP and badge" moment, and it appears after the reward, never before it.

The feedback sequence, strictly ordered

Result → XP → level → badge. Each step waits for the one before it. Firing them together produces a slot machine, which is what “no confetti” was protecting against in a different costume.

Publish flow

The v3.1 security fix, made operable. Send a request and watch the server refuse it.

What was wrong in v3. The migration granted authenticated a direct insert on achievement_verifications, checked only with auth.uid() = user_id. That proves the row is about you; it proves nothing about whether you earned it. Anyone signed in could mint a public, crawlable, branded page claiming any badge in the catalogue.
